# Yomo - Emotional Crypto Trading Companion

A Tamagotchi-inspired companion that connects to Solana wallets and reacts emotionally to trading behavior.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Features

- **Loading Screen**: Animated intro with glowing eyes and mouth
- **Yomo Character**: Animated companion with breathing effects
- **Emotion System**: 8 different emotions with smooth transitions
- **Variant Selector**: Switch between Dawn, Sage, and Twilight color variants
- **Wallet Integration**: Connect with Phantom wallet (demo mode available)
- **Particle Effects**: Floating particles for positive emotions

## Tech Stack

- React + Vite
- TailwindCSS
- Framer Motion
- Solana Wallet Adapter
